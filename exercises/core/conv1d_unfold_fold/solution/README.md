# Conv1D With Unfold And Fold (2 points)

Complete `unfold1d`, `fold1d`, and the forward and backward passes of `Conv1d` in the `src.conv1d` module. PyTorch's 2D `fold` and `unfold` operations may be used by treating sequences as 4D tensors. No `nn` functions or `for` loops are allowed except for the permitted fold and unfold operations.

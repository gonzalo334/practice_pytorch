# MaxPool2d (3 points)

Respect to the MaxPool2d function:

1. Development of an adaptation of fold and unfold to use them with the
MaxPool2d. No for-loops or functions from the nn package can be used, except
fold and unfold nn function to code the adaptations. (1 point)
2. Development of forward and backward of MaxPool2d. To code it, you have to
use the adaptations fold and unfold coded before, no other implementation will
be allowed. No for-loops or functions from the nn package can be used.
(2 points)

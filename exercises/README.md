# Exercises

This directory contains the implementation drills in two groups:

- `core/`: the original Deep Learning practice set.
- `advanced/`: extended exercises and proposed variants.

Each exercise is self-contained. Most folders include:

```text
exercise/
  src/
  tests/
solution/
  src/
  tests/
```

Use the root [README](../README.md) for the portfolio overview and
[docs/EXERCISE_INDEX.md](../docs/EXERCISE_INDEX.md) for the full categorized
map.
